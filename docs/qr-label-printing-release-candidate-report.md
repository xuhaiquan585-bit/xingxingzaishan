## 3. 渲染与文件验收

- 默认模板输出为 472 x 1890 px，PNG 密度信息为 600 DPI。
- 二维码由真实访问内容重新生成，保持正方形、四模块静区和黑白高对比。
- 默认提示文字为“写下此刻，提交后仅可查看”，并已验证可编辑后持久化为新版本。
- 正式 ZIP 包含 ID 命名 PNG 和 UTF-8 `二维码ID清单.csv`。
- 清单只包含二维码 ID、PNG 文件名、原二维码批次、任务编号、模板名和版本。
- 已验证最长 ID、文字越界、低分辨率图片拒绝和预览低清标识。

- 完整测试：517 项，514 通过，0 失败，3 项按环境条件跳过。

- 浏览器专项：拖拽、属性同步、提示文字保存、发布、创建任务、正式生成、两次下载、筛选、完成和逐码报废通过。

## 5. 数据库迁移与回滚边界

迁移 `008_add_label_print_production.sql` 仅新增模板、版本、资产、印刷任务及二维码印刷字段、索引、约束和触发器。迁移将既有二维码标记为“历史未分类”，不改变发行、激活、用户记录或区块链数据。

生产迁移前必须完成可恢复站外备份。正式文件生成前可以回滚应用并取消任务释放二维码；一旦产生正式印刷事实，数据库不可逆约束不得回退到允许二维码解绑或改绑的旧版本。详细启用顺序和停止条件见 `qr-label-printing-production-runbook.md`。
