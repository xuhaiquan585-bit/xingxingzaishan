# 记在星上真机与实体星贴验收清单

日期：2026-10-02
状态：待执行
适用候选：以执行时部署提交为准

## 1. 证据和安全规则

- 使用专门的验收批次和未激活星贴，不使用待销售库存或真实顾客记录。
- 至少准备两台手机、两个不同手机号和两个不同微信账号；建议一台 iPhone、一台 Android。
- 截图只保留星贴展示编号的必要尾号；访问凭证、完整手机号、Cookie、短信验证码、支付参数和完整对象地址不得进入报告。
- 每项记录：测试时间、设备和系统、入口、预期、实际、截图文件名、结论、异常编号。
- 出现写入结果不确定时立即停止重复点击，先由后台核对状态，避免人为制造重复提交。

## 7. 后台与质检权限

- 仅使用专门的验收质检账号执行停用和改密；不得操作唯一管理员或生产日常账号。
- 执行前记录验收账号 ID 和恢复方式，结束后恢复原启用状态及受控新密码，不在报告中记录密码或令牌。

| 编号 | 操作 | 通过标准 | 证据 |
| --- | --- | --- | --- |
| DEV-OPS-01 | 部署后刷新部署前已登录的后台和质检页面 | 旧版本签发的操作员令牌失效，页面要求重新登录；普通顾客会话不因此被批量登出 | 两端页面截图、顾客回看结果 |
| DEV-OPS-02 | 管理员尝试停用自己的当前账号 | 操作被拒绝且当前管理员仍可使用后台 | 固定错误码和后台截图 |
| DEV-OPS-03 | 管理员停用专用验收质检账号，质检端继续请求 | 已签发质检令牌立即返回 401 | 停用结果和质检请求状态 |
| DEV-OPS-04 | 重新启用同一质检账号后重试旧令牌 | 旧令牌仍返回 401；使用原有效密码重新登录后可访问 | 旧令牌状态、新登录结果 |
| DEV-OPS-05 | 修改专用验收质检账号密码 | 改密前令牌立即失效；旧密码失败，新密码登录成功 | 三次请求状态；不记录密码值 |

## 8. 完成门槛

- DEV-H5-01 至 DEV-H5-08、DEV-WX-01 至 DEV-WX-05、DEV-PHY-01 和 DEV-PHY-04 必须全部通过。
- 共创作为已上线能力，DEV-CO-01 至 DEV-CO-05 必须全部通过。
- DEV-ERR-01 至 DEV-ERR-05 任一失败均需建立缺陷编号并评估是否阻断销售。
- DEV-OPS-01 至 DEV-OPS-05 必须全部通过，并确认验收质检账号已恢复到约定状态。
- 不得用开发者工具截图代替微信真机证据，不得用屏幕上的二维码图片代替实体印刷星贴。
- 结果回填到 `docs/system-acceptance-20261001.md`；只有生产版本号、设备证据和后台状态能够相互对应时，才标记为真机通过。
